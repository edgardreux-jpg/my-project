# Pépite

Plateforme éducative CE1 à CM2 (Vite, React, TypeScript).

- `npm install` puis `npm run dev`
- `npm run build` (site) ou `npx vite build --mode single` (un seul fichier HTML)
- Démo : bouton « Voir une démonstration » (famille Mila CE1 et Sami CE2)

Données : Supabase (projet Pépite, auth e-mail + Google, RLS par parent). La démonstration reste locale.
`supabase/schema.sql` est un schéma prévu, non appliqué.
